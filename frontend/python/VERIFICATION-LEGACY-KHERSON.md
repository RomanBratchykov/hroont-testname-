## Реальний SoilGrids

Через WCS отримано GeoTIFF clay / 0–5 cm за координатами пілота.
Файл прочитано rasterio, сире значення поділено на 10, спостереження з одиницею `%`
і контрольною сумою файлу збережено в SQLite. Результат — модельований піксель,
не лабораторний аналіз і не середнє по полю.

## Доступність решти джерел

- CMR повернув HTTP 200 і по одній гранулі в обмежених пробних запитах для
  HLS S30/L30, GPM, NASADEM, SRTM та SMAP.
- SoilGrids WCS GetCapabilities повернув HTTP 200 без service exception.
- Legacy FAOSTAT: HTTP 521 у першій пробі, таймаут у повторній.
- Поточний офіційний FAOSTAT endpoint без токена: HTTP 401.
- Захищені завантаження HLS/GPM/SMAP/DEM та запит FAOSTAT з робочим токеном
  не перевірялися: облікові дані не підставлялися з вихідного документа.

HTML створено та перевірено автотестами на структуру, дані й екранування.
Візуальна перевірка скриншотом не виконана: у сесії немає доступного браузера.
